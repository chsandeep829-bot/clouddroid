# Free hosting reality

A free Cloudflare account can host the web dashboard and lightweight API functions. It cannot run a full Android virtual device.

A free-tier Linux VM, when available, is not a guaranteed 24/7 Android 17 host. Free tiers may reclaim idle instances, restrict compute, lack nested virtualization or GPU support, or change eligibility and quotas. Game compatibility and acceptable latency are separate requirements.

For a real always-on phone, use a provider that explicitly documents Android 17, persistent storage, remote display/input, and uptime terms. If the budget must remain exactly zero, the honest fallback is a dashboard that stays online while the Android device is unavailable or manually started on a free trial/limited host. Do not describe that as 24/7.
